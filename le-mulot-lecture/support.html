Your local library

Lecture keeps your books, notes and reading history on your device. You can open your library, add a book manually and save changes offline. Book search and online cover images need an internet connection. No Lecture account is needed for a local library.

Save a complete backup

  1. Open Settings → Backups & recovery.
  2. Choose Save complete backup and save the file using the system share sheet.
  3. Open Files and check that you can find the saved file. Keep a copy somewhere you can reach if this device is lost or replaced.

A complete backup includes books, notes, reading sessions, import history and appearance settings, along with retained source information. It stores cover addresses, rather than every online cover image. It does not include your old account’s sign-in credentials.

Restore a library

Select a complete backup from the opening screen or Backups & recovery. Review its contents before choosing Restore this library. Lecture checks the backup and opens a separate local library. The previous library remains on the device and can be reviewed from the recovery screen.

If the Home Screen icon cannot change, retry or choose Finish with the current Home Screen icon. If recovery is interrupted, reopen Lecture and finish the saved recovery.

Keep the original backup. Do not uninstall Lecture to clear a recovery error: uninstalling can remove its local files. Contact support with the message shown.

Older reading exports

Settings → Import books accepts supported Reading Brain JSON, Goodreads CSV and StoryGraph CSV exports. Review the proposed records before confirming. These formats carry less information than a complete Lecture backup, so keep their originals too.

An earlier online library remains separate. Creating a local library does not transfer that earlier library automatically.

Private iCloud backups

The private iCloud option is in Backups & recovery. It needs an Apple Account signed in to iCloud, available iCloud storage and a connection. Check the status shown in Lecture. Turning automatic backup off keeps existing saved copies, and an upload already sent may still finish.

Keep an independent complete backup in Files before changing devices. Recovery on a second device is still being validated for the initial release; do not rely on it as your only copy.

Send feedback

Settings → Send feedback opens an editable email draft. Lecture does not automatically attach books, notes or account details, or send the email for you. Only attach a library file if you intend to share its contents with support: it can include personal reading notes and original import information.
